# Privacy

Decision Room AI stores decision workspaces in Anna Storage for the signed-in
user. When the app is opened outside Anna for standalone preview, it uses that
browser's local storage instead.

Decision context is sent to Anna's model service only when the user explicitly
runs an AI analysis. The app does not require or collect third-party model API
keys, does not include advertising or analytics, and does not send decisions to
an external developer-operated server.

Users can delete individual decisions or clear all app data from Settings.
